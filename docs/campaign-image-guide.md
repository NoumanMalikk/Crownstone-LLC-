# Campaign image guide

Hero and editorial scenes must feature exact catalogue products.

## Allowed AI / generated usage

- Non-product backgrounds
- Architectural environments
- Background extensions
- Decorative lighting
- Reflections
- Abstract shadows
- Non-identifiable room scenes

## Not allowed

- Changing product shape, color, ports, buttons, dimensions or accessories
- Inventing packaging
- Using wrong model generations

Current campaign environment plates live in `public/campaigns/`. Exact product imagery is composited from catalogue assets in the UI.
