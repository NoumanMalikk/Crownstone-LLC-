# Image sourcing

Priority:

1. Verified supplier media
2. Official manufacturer retail media
3. Authorized distributor media
4. Original Crownstone photography of actual inventory
5. Professional photography commissioned for Crownstone

## Rules

- Exact manufacturer, model, generation, color, capacity, ports and accessories
- White or related solid background for main images
- No watermarks, retailer logos, hands, unrelated props or AI-generated product approximations
- Store files in `public/products/[product-slug]/`
- Record every asset in `data/image-credits.ts`

If an exact authorized image is unavailable, keep the development placeholder, mark `imageReplacementRequired: true`, and block production purchase.
